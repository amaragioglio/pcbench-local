Scope: PCBench desktop window (pywebview), Operate mode. Audience: home users and small-business owners; report must still serve a technician. Job: answer "Is my PC safe?" first, then "Is it performing well?", with fix steps.

## Direction contract

THESIS: The scan is a mechanic's multi-point inspection sheet: every check is a printed line with three lights, one lit. It refuses the category default of a big score gauge and card grid.

OWN-WORLD: Cool form-paper ground, white sheet panel, blue-gray printed rules, deep inspection-ink blue shell bar and primary action; red, amber and green appear only as the lit light of a row. Bahnschrift caps for section heads and figures, Segoe UI Variable for body.

STORY: The visitor presses one button, watches the sheet being filled line by line, reads one plain verdict, opens the red lines first and follows numbered steps.

FIRST VIEWPORT: Ink header with name, language switch and admin status. Left 320px summary sheet: date, verdict sentence, red/amber/green tally, primary "Revisar mi PC", save report. Right: tabs Seguridad / Rendimiento over the checklist, urgent lines first, each expandable.
